# 复刻一整套模版,并且证明它像

老板的原话:`你要抄别人家的你就整套都抄` · `抄完一个才抄另外一套` ·
`我要图片排版完全一样 字体 动效` · `是准确了 可是还不是100%`。

这份 skill 记的是**怎么做**跟**哪里会骗人**。工具是 `npm run align`。

## 一次一套,顺序固定,不要跳

```
1  npm run align -- <风格> --refresh     采一次参考，存成带日期的快照
2  看 .screenshots/align/<风格>-diff.jpg  只贴不及格的那几段
3  改一件                                  一次一件
4  npm run align -- <风格>                 只重量我们这一边（21 秒）
5  回到 2
```

**第 2 步不可以跳。** 尺子回答「一不一样」,永远回答不了「好不好看」。
今天最凶的三个洞全部是**准备照着报告动手改页面的那一刻**才现形的,
不是坐着审代码审出来的。

## 尺子量什么(每套约 58 项)

| 组 | 项 |
|---|---|
| **版面** | 段数 · 整页高 · 段均高 · 配得上的段 · 每一段的高 |
| **照片** | 张数 · 满宽的 · 半幅的 · 最高一张 · 长宽比 |
| **字体** | 载入了没 · 大写比小写宽 · 小写多高 · 墨量 · 字宽 · 字级 · 字距 · 级差 h2/h1 · 行距 · 正文字级 |
| **结构** | 版心 · 满边的段 · 逐段的盒子(图/钮/字 · 位置 · 圆角 · **顺序** · 几栏) |
| **颜色** | 逐段底色 · 逐段用几个颜色 · 对比跨度 · 有颜色的面积 |
| **动效** | 时长 · 缓动 · 滚动进场(位移) · 四种 hover(含速度) · 有影片 |
| **手机** | 390px:段数 · 整页高 · 版心 · 最宽的图 · 张数 |
| **留白** | 段间 · 段内的气 · 段内的缝 |

## 它会拒绝,而不是给你一个错的答案

- 参考页有超过一段是空的 → **exit 1**(还没载完就量,每一根轴都是错的)
- 写库没把 demo 站切到这一套风格 → **exit 1**(会量到上一套,然后印出五十项关於别人的读数)
- 图或字掉在所有段之外 → 报错(分段吞掉了东西)
- 量不准的数字(几栏字)→ **只印不判**
- 两边都量不到 → **量不到**,不是过关

## 会骗人的地方 —— 今天一天踩出来的,不要再踩

**关於页面长什么样的三个错假设**(每一个都让尺子看不见半个页面):

1. **照片一定是 `<img>`** → CSS 背景图看不见。Newel 的第一屏是背景图,
   尺子报「满边的段 0/7」「最宽的图 20%」,那 20% 是他们的 **logo**。
   **照那份报告改,会去拆掉我们做对的满边第一屏。**
2. **被包住的一定是包装层** → 并排叠着的兄弟层被丢掉。
   包装层丢掉没差,兄弟层丢掉整块内容消失。**被包住要「并进去」,不是「丢掉」。**
3. **每一块都是某一段的子孙** → Wix 有窄的 comp 是那些段的**兄弟**,里面的东西谁也装不到。
   **一段是页面上的一段垂直范围**,所以每个盒子按它的垂直中心归段。

**四个「印出可信数字的坏尺」**:

4. 正则里写 `\s` —— 那是「一个反斜线加 s」,永远不匹配。
   **逐段颜色的判定因此从来没进过总数**:画面一排 XX,结论当它不存在。
5. 动效的位移 `none → matrix` 回传常数 **60**,三套整齐印出「位移 60px」。
   **`none` 不是量不到,是单位矩阵。**
6. 段落门槛写死 `w >= 1300` —— 390px 上没东西有 1300 宽,
   模版回报「段数 0 · 整页高 0px」,**一个长得像读数的空答案**。
7. `decode()` 可以永远不返回(lazy 图滚过去又滚回来)。
   `.catch()` 接得了「拒绝」,接不了「不回来」。**每张给 1.5 秒上限。**

**三个「名字说得比它量得多」**:

8. **「衬线/无衬线」量不了衬线** —— 它算的是大写宽 ÷ 圆的小写宽,那是字形比例。
   它报 1.21,而唯一接近的是一套**无衬线**;放大 1500px 看,他们的 R 跟 j 有清楚的
   **flare(笔画外扩)**,不是 serif。已改名「大写比小写宽」。**衬线与否只能用眼睛。**
9. **墨量不看实际字重** —— 探针写 `100px "字体"`,没有字重就永远量 400。
   改了字重画面变细而数字纹丝不动。
10. **「标题字重」判宣告的数字** —— 两套字的同一个 400 可以差五倍黑。
    判**结果**(墨量),不判**宣告**。

**两个「同一个问题两个答案」**:

11. 「段数」用 ±1 判过、「配得上的段」判不过 —— 同一份报告两个相反答案。
12. 「照片张数」数所有 `<img>`(含图标),「照片 SHOTS」只数 ≥120×90 ——
    **同一个词两个定义**。

**两个排序/几何的噪音**:

13. **并排的两块没有先后**,而按精确 y0 排序会给它们一个。
    他们的照片比标题高几个像素 → 同一个设计一边读「图→字」一边「字→图」。
    **先归行(每 6 个百分点)再按左边缘排。**
14. **画面外的盒子不是内容** —— 轮播里还没转到的那几张会报出「字 -93–-73」。

**一个「答不了却在答」**:

15. **照片铺满的段没有「设计的底色」** —— 比的是两张不同的照片。
    盖过八成就不判。

## 改页面的时候,这几件今天证明是对的

- **一个值只要每套风格要能自己决定,就得在 globals 决定,不然就是决定不了。**
  写进组件 class 的字重(0,1,0)赢过风格的宣告;写进 props 的 `look` 赢过 prefer;
  行业模版写死的东西风格永远改不动。
- **用一段的总高去反推每一张照片的形状,形状一定跑掉。**
  段太高就减张数,不要压扁每一张。
- **气是比例,不是一个 rem。** 段长大了,同一个 rem 就变成另一个百分比。
- **编号是形状,不是内容。** 一个数字不宣称任何事,所以对每个客户都成立 ——
  缺内容的地方给它一个诚实的位子,不要整个不画(老板:`不然就用占位图`)。
- **买不到的东西不要买。** 一个改动没换到那个数字、却弄坏另一个,退掉。

## 什么不该追到 0

一把逼到 0 的尺,会逼你把询价表格砍掉、把别人的 logo 换成图库照片。
判「这个差异该不该修」没有尺,只有判断。已经写下来的:

- **我们多一段询价表格** —— 他们的模版折进页脚或根本没有。
  砍掉客户官网上唯一会有钱进来的那一块去换一个数字,是拿产品换分数。
- **他们的 logo 墙** —— 我们那一格画店名。塞图库照片进去,那一格讲的是别人的故事。
- **他们页脚开头是 logo 图档** —— 我们把店名排成字。同一个角色,一边算图一边算字;
  在客户的公开页脚放一个空 logo 框,比印他的店名更差。
- **我们没有他们的授权字体** —— 但**种类**要对(老板:`是字体的种类不一样`)。
  做法:把手上每一套字在 200/300/400 量一遍,对参考的三个读数取最近的。
  台账 实测 Geist 200 差距 0.03,原本的 Newsreader 400 是 0.91。
