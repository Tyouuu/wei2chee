### 8. 选了英文，画面上还是一堆中文（他 2026-08-25 报的）
> `还有一个事情就是明明选择了英文 作为language 为什么还是有那么多华语字的呢
> 加一段是华语 你帮我去处理一下这个问题 写进去任务里面`

**要先分清楚是哪一种**，因为这里有两个语言、两条规则（[founder-points.md](./founder-points.md) 第 13 条）：
- **系统语言**（`projects.system_language`）—— 客户的系统对他的客人讲什么话
- **介面语言**（`locale`，网址 `/zh/` 或 `/en/`）—— Formae 对老板讲什么话

原本的设计是「系统对客户讲英文，Formae 对老板讲中文」，所以编辑器的按钮是中文是**故意的**。
但他明确说不对 —— 那就以他为准，而且这里很可能真的有 bug：

- [x] 查 `/en/portal/...` 下编辑器的中文是不是**写死的**（`puck-config.tsx` 里每一个
      `label:` 都是中文字面量，没有走 next-intl；「加一段」在 `insert-affordance.tsx`）。
      如果是，那不管他选哪个 locale 都会看到中文 —— **这才是他讲的那件事**
- [x] 区块名、分类名、字段名、款式名（489 个）+「加一段 / 换款式 / 改文字」全部跟着 locale 走了
      （`labels-en.ts` 对照表 + `localisedPuckConfig(locale)`；中文仍是唯一真相，英文是它的投影）
- [x] 首页那句大标题不再拿中文顶上去（`summary_en` 一直有，从来没人读）
- [x] **新加一块的示例内容跟着系统语言走了** —— `sample-en.ts`，166 条内容字串。
      **两个投影、两个设定**：编辑器的字跟 locale 走，块里的内容跟 `system_language` 走。
      只翻**含中文字的字串** —— `defaultProps` 里还有 id、href、图标名、颜色 token，
      翻那些等於把能用的块弄坏。
      顺手修了一个原本就有的：`SmallStat` 的 `period` 预设写成「vs 上个月」，
      而组件自己已经会加前缀 —— 一直是「vs vs 上个月」，要等英文投影把两个 vs 摆在一起才看得出来。
- [x] **旧分析回填完了** —— `npm run backfill:summary-en`（预设只讲不做，`--write` 才动手）。
      **是翻译不是重跑分析**：重跑会产生一份新的分析（模块、流程、询价落点都可能不一样），
