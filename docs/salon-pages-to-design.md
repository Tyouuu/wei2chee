# 发廊（saloon）第一版：只画这些 —— 交给你一次画完

2026-09-25。你问：`真的需要那么多页面吗`。**不需要。**

上一版我按「旧版有的都带过来」列了 7 页 ＋ 15 块，方法错了。该问的是：
**一间发廊的老板每天问哪几句话？他的手写簿上有没有这一格？**（[重点 34]）
按这个筛，**第一版只要 1 页 ＋ 5 小块**。其余不是不做，是排后面（[重点 18]）。

⚠️ 这是我的建议，你点头才算数。

## 第一版：只画这些

**1 个新页**
1. **开销** —— 记一笔开销（可拍收据）· 这个月花了多少、花在哪、付给谁 · 一张表。
   （手写簿上有「房租 / 进货 / 水电」这一栏；收工页只有当天的零用钱，没有记的地方，也看不到整个月）

**5 个小块（都不是页，是在已有的页里加一点）**
2. **总览多一张卡「今天要跟」**：系统自己发现的事，最多三条（套票只剩一次 · 客人很久没来 · 放了飞机 · 会员该缴费……），每条一句话、可以「先不管」
3. **客人档案顶上多两格数字**：储值余额 · 放过几次飞机（欠款有才多一格）。不要单独的块
4. **发票：点一笔 → 可以「冲正」**（钱不删，开一笔相反的；柜台按错是天天会发生的事）
5. **边栏：退出**（新版现在没有退出）
6. **师傅页：打卡上班 / 下班的按钮**（可选；现在只显示「没打卡」和最近记录，没地方按）

## 我这边做，不用你画
- **收银结账时，自动记下「这一次做了什么」**（哪位客人 · 做了哪些服务 · 谁做的）。
  新版报表里的「服务排行」「师傅产出」靠它才有数字，而收银台现在只记钱、不记做了什么。
  这样日程面板里**不用再画「加一行」**——购物车本身就是「这一次做了什么」。（我等你点头再做）

## 延后（不是不做，排在第一版后面）
| 项 | 为什么可以后 |
|---|---|
| 评价 | 手写簿上没有；不影响每天开门 |
| 网站询价 | 是官网的事，放进官网设置里，不占每天的系统 |
| 发薪 · 帐 · 税 | 老板每月甚至一辈子才开一次；e-Invoice 要做，但小发廊排后面 |
| 每周上班时间 | 小发廊师傅的班多半是固定的 |
| 走单轮位 | 有的店靠客人点名，不轮 |
| 客人自己的连结（取消 · 留评价） | 要发出去才有用，而 WhatsApp 还没接（[任务 11]）|
| 欠供应商 | 进货单已经有，「欠多少」可以后 |
| 预约面板里的订金 | 订金规矩已经在「设置」里，面板里先不放 |
