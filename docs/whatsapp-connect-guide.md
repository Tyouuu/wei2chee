# 帮一个客户接上她自己的 WhatsApp——路线一，手动做，今天就能用

2026-09-26。[任务406] 定的路线一：客户自己开一个只给自己用的连结，不用审核、
不用商家认证、不用等 Formae 公司注册。这份是那一支流程的清单，第一个真客户
上门用得到。**这是给你（老板）自己动手做的清单，我这一边没有账号、没有电话，
做不了这几步。**

⚠️ 这份清单是照 Meta 官方文件写的规格（不是我实测过的画面）——第一次真的走
一遍，遇到跟这里不一样的地方，把真的画面记下来，回来改这份清单。

## 要先备好的东西
- 客户的一支**没有在用一般 WhatsApp App** 的手机号码（这支号码接上 API 之后，
  没办法再用手机上的 WhatsApp App 登入，要嘛是一支新号码，要嘛先把旧号码从
  WhatsApp App 上登出）
- 客户的 Facebook 账号（用来登入 business.facebook.com）

## 六步
1. **开一个商业平台（Business Portfolio）**——`business.facebook.com` → 用客户
   自己的 Facebook 账号登入 → 建一个新的商业平台，名字打客户的店名
2. **建一个 App**——`developers.facebook.com` → 我的 App → 建立 App → 选
   「商业」类型 → 加「WhatsApp」这个产品
3. **加电话号码**——WhatsApp → API Setup → Add phone number → 打客户的号码
   → 会发一次验证码（短信或语音）到那支号码，输入验证码完成
4. **拿到两样东西**：
   - **Phone Number ID**——在 API Setup 那一页，一串数字，不是电话号码本身
   - **永久的 Access Token**——商业设置 → 用户 → 系统用户 → 新增一个系统用户
     （给管理员权限）→ 产生权限码，勾 `whatsapp_business_messaging` 跟
     `whatsapp_business_management` 两个权限 → 产生的那一串字**要存好，
     只显示一次**
5. **接 Webhook**（这一步要我这边配合，不是你一个人做）：WhatsApp →
   配置 → Webhooks，要填一个网址跟一个验证字——这两样等 Formae 那一边有
   一个真的号码要接的时候，我再给你
6. **把 Phone Number ID 跟 Access Token 给我**——填进[任务418] 租户设置里
   「WhatsApp Automations」那个分页签（现在是空的，等真的接第一个号码那天
   才会做出表单）

## 每一步卡住可能是什么
- **验证码收不到**：号码正在别的 WhatsApp App 上登入着，先登出
- **系统用户产生不了权限码**：账号不是那个商业平台的管理员，要先把自己加成
  管理员
- **加号码那一步说号码已经被用过**：这支号码以前接过别的 WhatsApp Business
  账号，要先去 `wa.me` 或者官方的「解除关联」流程把旧的接口断开

## 现在还不用做的
- Webhook 那一步（第 5 步）——没有真客户之前，我这边没有东西可以让它接，
  先不用配
- [任务418] 那个分页签的表单——等真的有第一个号码要接的时候再做，
  不然是一个存不到任何地方的空表单
