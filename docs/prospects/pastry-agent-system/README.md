# 包点代理订单系统——另一位 Formae 客户，还没确定要不要做

跟 Formae（沙龙／补习／车厂那套 SME 系统）是不同的客户、不同的生意：这位做的是
点心/包点的代理分销——总公司定价 RM100，老板以代理身份拿货 RM70，再卖给茶餐厅
RM80，茶餐厅卖消费者 RM90。订单要同时出给代理和总公司两份（内容不同，价钱互相
保密）。

**这个资料夹活在 `prospect/pastry-agent-system` 这条分支上，不在 `main`**——因为
这位老板还没确定要不要做，[重点41](../../founder-points.md)：一次是个案，先隔离，
不要动共用代码；这里连「个案」都还没真的开始，先把研究跟方法论放着，不混进
`main` 上 Formae 自己的 `founder-tasks.md`。

- `research.md` —— 对这门生意做的深度调研：餐厅扫码点餐行业的做法能照搬哪些、
  价格怎么对两边保密、货权与冷链、马来西亚的收款网关、云打印机、合规提醒
  （电子发票门槛、买卖还是代理、SST、PDPA）。结论先说，附第一版精简范围跟
  一份「先问清楚再动工」的问题清单。
- `software-playbook.md` —— 老板自己整理的一份通用「用 Claude 快速做软件」方法论
  （来自他另一个项目 VIBE 456），跟这门生意本身无关，是他随这次一起留下的参考。

**什么时候该动**：老板确认这位客户真的要做了，再把这当成一个新的 Formae 「个案」
开工——先按研究报告附一的精简范围做第一版，不要一次把所有东西都做出来。
